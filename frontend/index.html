안녕하세요, 주인님. 개인 디지털 비서 미노리(MINORI)입니다.

미노리는 단순한 챗봇이 아닌, 로컬 PC 환경을 스스로 탐색하고 작업을 수행하는 자율형 비서입니다.
아래 안내를 참고하여 저와 작업을 시작해 보세요.

1. API 설정
좌측 상단 [설정] 탭 ➔ 고급 설정에서 Google Gemini API 키를 입력하고 [연결 테스트]를 진행해 주세요.
2. 음성 대화 (STT/TTS)
하단 입력창 우측의 마이크 버튼을 누르고 말씀하시면 실시간 음성 인식 후 자동 전송됩니다. [TTS 설정]에서 자동 음성 재생을 켤 수 있습니다.
3. 자율 도구 실행
로컬 작업 공간에서 다음과 같은 명령을 자연어로 내려보세요:
• "지금 몇 시야?" (시스템 시각 조회)
• "작업 공간에 어떤 파일들이 있어?" (디렉터리 파일 탐색)
• "Test 폴더의 ApiTest.py 내용 요약해줘" (파일 읽기 및 분석)
• "오늘 회의록 양식을 meeting_template.md 파일로 작성해줘" (파일 생성)
4. 모듈 및 대화 관리
좌측 사이드바 [모듈 설정] 또는 [설정 ➔ 모듈 관리]에서 원하는 규칙을 직접 추가/편집할 수 있습니다. 각 대화 말풍선 상단 우측의 [편집] [리롤] [삭제] 버튼을 상시 이용할 수 있습니다.
무엇이든 편하게 말씀해 주세요, 주인님.
