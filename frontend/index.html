안녕하세요, 주인님. 개인 디지털 비서 미노리(MINORI)입니다.

미노리는 단순한 챗봇이 아닌, 로컬 PC 환경을 스스로 탐색하고 작업을 수행하는 자율형 비서입니다.
아래 안내를 참고하여 저와 작업을 시작해 보세요.

1. API 및 오프라인 LLM
좌측 상단 [설정] 탭 ➔ AI 모델 설정에서 Gemini API 키를 입력하거나, 인터넷 없는 완전 오프라인 Ollama 모드를 선택할 수 있습니다.
2. 이미지/문서 드래그 & 제작
캡처 스크린샷이나 문서를 채팅창에 끌어다 놓거나(Ctrl+V 지원) 분석을 맡기세요. "사이버펑크 도시 그려줘"라고 하면 이미지를 즉시 생성해 띄웁니다.
3. 실시간 검색 · 날씨 · 타이머
• "오늘 서울 날씨 어때?" / "최신 AI 뉴스 검색해줘"
• 뉴스/블로그 URL 링크 본문 요약
• "10분 뒤에 알려줘" (카운트다운 후 음성/토스트 선제 알림)
4. plugins/ 자동 확장
D:\AIproject\plugins\ 폴더에 파이썬 파일(.py)만 넣으면 서버 재시작 없이 즉시 미노리의 새로운 기술로 자동 등록됩니다.
무엇이든 편하게 말씀해 주세요, 주인님.
미노리 환경 설정 대시보드 모듈 규칙, 로어북, 음성 엔진(STT/TTS), AI 파라미터를 넓은 화면에서 직관적으로 관리하세요.
